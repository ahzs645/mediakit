Media Studio · aligned overlay analysis

Four original SVG references, including the weekend Story from the new Section 1 montage, are aligned at their native viewBox. The dynamic output uses October 5–9 / October 10–11, 2026. Reference day numbers are static; output dates follow the real calendar.

  • The original heading silhouettes and October 2026 Salted lettering are retained. Heading and month can move independently.
  • Every format uses a 4% top heading / bottom frame margin by default. Badge heights default to 120%, with a 100–150% control. These deliberate spacing changes appear in the difference images.
  • The watermark repeats one complete original eleven-letter vector logo on the original staggered lattice, across the full canvas. Duplicate source logos are removed and aspect-ratio padding also contains the pattern.
  • The original paper photograph is directly tinted for each day badge. Its texture survives browser image/canvas rendering without depending on Figma blend modes.
  • Other months use Kalam unless the user loads a local font such as Salted. Local font files stay in browser storage and are excluded from the public repo and project backups.
